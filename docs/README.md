# `docs`

Documentation of `@mantlebee/ts-random`.

- **[`release-notes/`](./release-notes)** — one file per version
  (`<version>.md`): what changed and how to upgrade. They are also included in
  the API site.
- **`api/`** — the API site generated by typedoc (`npm run doc`). Not versioned:
  it is published to GitHub Pages by `npm run doc:publish`.
