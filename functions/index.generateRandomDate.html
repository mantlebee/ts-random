    Function generateRandomDate

    • generateRandomDate(
          endDate?: Date,
          startDate?: Date,
          options?: GenerateRandomDateOptions,
      ): Date

      Generates a random date in the given range, both included, whose time is within the given hours, minutes and seconds. Generated dates have no milliseconds, and each allowed second in the range has the same chance to be generated. Around a daylight saving time change, the local times that are skipped are never generated, and the ones that are repeated are generated at their first occurrence only. The given dates are not modified.

      Parameters

      • endDate: Date = ...

        Ending date range, default is now.

      • startDate: Date = ...

        Starting date range, default is 1970/01/01 00:00:00 in local time.

      • options: GenerateRandomDateOptions = {}

        Hours (0-23), minutes (0-59) and seconds (0-59) allowed, both included.

      Returns Date

      a random date in the given range.

      Example

      Generates a random date between 1970/01/01 and now.

      generateRandomDate()

      Example

      Generates a random date of 2024, during the office hours.

      generateRandomDate(new Date(2024, 11, 31, 23, 59, 59), new Date(2024, 0, 1), {
        hoursFrom: 9,
        hoursTo: 17,
      })

      Throws

      RangeError if a date is invalid, if startDate is after endDate, if an option is out of its range or its from is greater than its to, or if no date in the range has an allowed time.
